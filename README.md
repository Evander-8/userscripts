# 油猴脚本

存放本人维护的油猴（Tampermonkey）脚本，一个脚本一个文件夹，文件夹内自带该脚本的介绍与截图。

| 脚本 | 适用站点 | 说明 |
| --- | --- | --- |
| [LINUX.SB助手（二开版）](./LINUX.SB助手/) | [linux.sb](https://linux.sb) | 积分分析 / 称号合成统计 / 称号市场监控 / 幸运打赏，基于原作者「豆包本包」的原版二开 |

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开对应脚本文件夹里的 `*.user.js`，全文复制
3. Tampermonkey → 「添加新脚本」，粘贴并保存（Ctrl / Cmd + S）
4. 打开目标站点，脚本自动生效

各脚本的详细功能、截图与更新记录见其文件夹内的 README。
