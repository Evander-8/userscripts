> **🌟 v1.7.5 更新**：**修复楼层操作按钮的图标消失（删除 / 置顶只剩空壳）！**
> - **问题现象**：帖子楼层右下角那排操作按钮里，「删除」「置顶」只剩两个空的玻璃胶囊，图标不见了。
> - **根因**：站点图标是用 `.icon-action::before` 的 14px 方块 + `mask: url(svg)` 画的，按钮本身是**定尺**的（`.icon-action { width: 24px }` 配 `.post-ops button.sb-limit-edit-time-delete { padding: 0 }`）。本脚本给 `.post-ops button` 强加了 `padding: 4px 14px`，内边距总量超过 24px 后，`box-sizing: border-box` 下内容盒被压到 **0 宽**，作为 flex 子项的伪元素随之塌成 **0px** —— 图标整条消失，只剩我们画的胶囊底。
> - **修复**：`.post-ops` 的内边距改由站点掌控（脚本只负责上色、圆角与高光），定位/尺寸一律不碰；并追加 `.icon-action::before` 等图标伪元素禁止 `flex-shrink` 的兜底，防止同类问题再犯。
> - **范围核对**：本地复现页实测，修复前 `.icon-delete / .icon-quote / .icon-edit` 的伪元素宽度均为 **0px**，修复后恢复 **14px × 14px**。

> **🌟 v1.7.4 更新**：**修复毛玻璃把站点 fixed 浮层“吃掉”的问题！**
> - **问题现象**：点编辑器工具栏的表情按钮，弹层不出现 / 弹在错位置 / 被裁；全屏编辑器、灯箱、弹窗遮罩等 `position: fixed` 浮层同样受影响。
> - **根因**：`backdrop-filter` 会让元素**成为后代 `position: fixed` 的包含块**。站点的 `.nb-editor-panel` 由 JS 用 `getBoundingClientRect()` 按**视口坐标**定位（官方注释即写明「面板用 fixed 浮层……位置由 JS 计算」），而 `.main-panel` 与回复面板上写的 `backdrop-filter` 把包含块夺走了——弹层于是相对面板而非视口定位，错位量恰等于该面板的视口位置（随滚动变化），再叠加 `overflow: hidden` 直接被裁掉。
> - **修复**：`.main-panel` 与「回复面板 / 登录回复提示卡 / 回复编辑面板」不再把 `backdrop-filter` 写在元素自身，改由 `::before` 伪层（`inset: 0` + `border-radius: inherit` + `z-index: -1` + `pointer-events: none`）承载模糊。**观感完全不变**，但不再夺走包含块。
> - **顺带恢复**：凡嵌在毛玻璃容器里的 `fixed` 元素——`.nb-editor-field.nb-editor-full`（全屏编辑器）、`.image-lightbox-overlay`、`.modal-backdrop`、`.toast`、`.back-to-top-button` 等——一并恢复正常。

> - **彻底解决刷新与切页闪烁 (Zero-FOUC)**：

>   - **SPA / PJAX 页面切换零闪无缝适配**：劫持 `pushState` / `popstate`，在页面无刷新切换时同步刷新样式守护与背景层，切页如同原生应用般平滑。
> - **120fps ProMotion 极致丝滑性能引擎**：
>   - **消除冗余嵌套重复模糊 (Zero Nested Blurs)**：剔除 `.post-item` 列表行、徽章、引用块、输入框及子卡片原本重复叠加的多层 `backdrop-filter`，由外层 `.main-panel` 统一承载高斯模糊，子元素直接透光，GPU 显存带宽与填充率消耗锐降 90%！

>   - **滚动极速保护 (Scroll Performance Mode)**：滚动期间自动添加 `.lsb-scrolling` 暂停高开销的指针悬停重排计算，让滚轮与触控板滑动如丝绸般顺滑细腻！

## 🌟 核心视觉与交互特色

1. **🌊 真实 SVG 液态曲面光线折射（Optical Refraction）**
   - 彻底超越传统纯 CSS `blur` 的死板灰度，引入底层 `feTurbulence` + `feDisplacementMap` + `feSpecularLighting` 滤镜通道。
   - 透过玻璃能感受到环境光与背景图像真实如水波、曲面透镜一般的轻微光线折射与高光曲面聚光。

2. **💎 双重内发光棱线与高光流体（Specular Rims & Shimmer Sweep）**
   - **双重内高光**：`inset 2px 2px 1.5px rgba(255, 255, 255, 0.95)` 与 `inset -1px -1px 1.5px 1px rgba(255, 255, 255, 0.4)`，模拟真实玻璃边缘的通透棱角反光。
   - **悬浮动态扫光（Shimmer Light Sweep）**：鼠标滑过帖子、按钮、胶囊标签时，一道纯净的白色光斑如流光般平滑掠过（Sweep Transition）。

3. **🛸 悬浮胶囊码头顶栏（Floating Capsule Dock）**
   - 将原版扁平顶栏升华为像 macOS 状态栏一样的现代居中流体玻璃胶囊，四角呈圆润弧形（`rounded-full`），悬浮于内容之上。

4. **🍮 果冻弹性动力学交互（Jelly Spring Easing）**
   - 采用 `cubic-bezier(0.175, 0.885, 0.32, 1.4 ~ 2.0)` 物理回弹缓动，卡片悬浮、按钮点击、头像悬停带有Q弹灵动的果冻微反馈。

5. **🌓 动态极光流体背景与深浅色模式自适应**
   - 内置 **流体极光（Aurora）**、**赛博霓光（Cyber）**、**晨曦柔光（Dawn）**、**极简素雅（Minimal）** 4 种背景色调与环境光斑。
   - 完美适配论坛自身夜间模式，自动切换为深邃高透亚克力防眩光黑夜玻璃。
   - 支持自定义网络壁纸图片（URL）。

6. **✨ 悬浮交互式设置面板（Settings Widget）**
   - 页面右下角常驻精致的 **悬浮晶莹齿轮按钮 ⚙️**。
   - 支持实时配置：
     - **背景风格**（极光/赛博/晨曦/素雅/自定义壁纸）
     - **毛玻璃模糊度**（0px ~ 40px，默认 4px）

     - **字体颜色自定义**：正文主文字 / 帖子与标题 / 链接与导航 / 次级元信息 / 按钮与胶囊 5 个区域，每个区域分「浅色 / 深色」两套色值（共 10 组取色器），支持色盘取色、Hex 输入、单项清除与一键重置默认
     - **SVG 液态折射滤镜开关**
     - **悬停扫光高光开关**

## 🚀 安装步骤

### 准备工作
确保您的浏览器已安装主流用户脚本扩展之一：
- **Tampermonkey（篡改猴）**
- **Violentmonkey（暴力猴）**
- **ScriptCat（脚本猫）**

### 安装方式
1. 点击浏览器右上角油猴图标，选择 **“添加新脚本”**（Create a new script）。
2. 将本目录下的 [`linux-sb-liquid-glass.user.js`](./linux-sb-liquid-glass.user.js) 全部代码复制并覆盖粘贴进去。
3. 按 `Ctrl + S`（Mac 上为 `Cmd + S`）保存脚本。
4. 打开或刷新 [https://linux.sb/](https://linux.sb/)，即可立即感受液态玻璃的视觉体验！
