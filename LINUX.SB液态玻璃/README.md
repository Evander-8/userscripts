## 🌟 核心视觉与交互特色

1. **🌊 真实 SVG 液态曲面光线折射（Optical Refraction）**
   - 彻底超越传统纯 CSS `blur` 的死板灰度，引入底层 `feTurbulence` + `feDisplacementMap` + `feSpecularLighting` 滤镜通道。
   - 透过玻璃能感受到环境光与背景图像真实如水波、曲面透镜一般的轻微光线折射与高光曲面聚光。

2. **💎 双重内发光棱线与高光流体（Specular Rims & Shimmer Sweep）**
   - **双重内高光**：`inset 2px 2px 1.5px rgba(255, 255, 255, 0.95)` 与 `inset -1px -1px 1.5px 1px rgba(255, 255, 255, 0.4)`，模拟真实玻璃边缘的通透棱角反光。
   - **悬浮动态扫光（Shimmer Light Sweep）**：鼠标滑过帖子、按钮、胶囊标签时，一道纯净的白色光斑如流光般平滑掠过（Sweep Transition）。

3. **🛸 悬浮胶囊码头顶栏（Floating Capsule Dock）**
   - 将原版扁平顶栏升华为像 macOS 状态栏一样的现代居中流体玻璃胶囊，四角呈圆润弧形（`rounded-full`），悬浮于内容之上。

4. **🍮 果冻弹性动力学交互（Jelly Spring Easing）**
   - 采用 `cubic-bezier(0.175, 0.885, 0.32, 1.4 ~ 2.0)` 物理回弹缓动，卡片悬浮、按钮点击、头像悬停带有Q弹灵动的果冻微反馈。

5. **🌓 动态极光流体背景与深浅色模式自适应**
   - 内置 **流体极光（Aurora）**、**赛博霓光（Cyber）**、**晨曦柔光（Dawn）**、**极简素雅（Minimal）** 4 种背景色调与环境光斑。
   - 完美适配论坛自身夜间模式，自动切换为深邃高透亚克力防眩光黑夜玻璃。
   - 支持自定义网络壁纸图片（URL）。

6. **✨ 悬浮交互式设置面板（Settings Widget）**
   - 页面右下角常驻精致的 **悬浮晶莹齿轮按钮 ⚙️**。
   - 支持实时配置：
     - **背景风格**（极光/赛博/晨曦/素雅/自定义壁纸）
     - **毛玻璃模糊度**（0px ~ 32px）
     - **面板不透明度**（30% ~ 95%）
     - **水滴胶囊圆角**（10px ~ 32px）
     - **SVG 液态折射滤镜开关**
     - **悬停扫光高光开关**
     - **胶囊悬浮顶栏开关**
     - **流动极光动画开关**

## 🚀 安装步骤

### 准备工作
确保您的浏览器已安装主流用户脚本扩展之一：
- **Tampermonkey（篡改猴）**
- **Violentmonkey（暴力猴）**
- **ScriptCat（脚本猫）**

### 安装方式
1. 点击浏览器右上角油猴图标，选择 **“添加新脚本”**（Create a new script）。
2. 将本目录下的 [`linux-sb-liquid-glass.user.js`](./linux-sb-liquid-glass.user.js) 全部代码复制并覆盖粘贴进去。
3. 按 `Ctrl + S`（Mac 上为 `Cmd + S`）保存脚本。
4. 打开或刷新 [https://linux.sb/](https://linux.sb/)，即可立即感受液态玻璃的视觉体验！
